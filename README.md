# Kestrel Homes

A responsive real estate website showcasing homes for sale and rent. The page includes property listings, neighborhood information, a featured home, agent details, and a contact section.

## Features

- Search listings by property name or neighborhood.
- Filter listings by property type and maximum price.
- Browse property photos in an image lightbox.
- Navigate between listings, locations, featured properties, agents, and contact information.

## Run locally

Open `INDEX.HTML` in a web browser. No build tools or package installation are required.

## Project files

- `INDEX.HTML` - page structure and property content.
- `STYLE.CSS` - layout and responsive styling.
- `SCRIPT.JS` - listing filters, image lightbox, and page interactions.
- `IMG/` - property and agent images used by the page.
